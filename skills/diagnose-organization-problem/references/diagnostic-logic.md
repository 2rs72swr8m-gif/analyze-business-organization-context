# 组织问题诊断逻辑

## 1. 从结果倒推，不从组织图出发

使用以下因果链检查判断：

`经营或管理症状 → 关键价值流与决策事件 → 竞争性原因 → 组织系统机制 → 可选择干预 → 结果验证`

若无法指出哪个价值流、决策或协作事件受到影响，就不要进入组织结构讨论。

## 2. 八类竞争性解释

| 解释 | 典型机制 | 需要的证据 | 常见误判 |
|---|---|---|---|
| 外部环境或资源 | 市场、监管、客户、供应或预算约束 | 外部数据、客户事实、资源约束 | 把不可控因素归因于内部组织 |
| 战略与优先级 | 方向冲突、取舍缺失、频繁变更 | 战略文件、资源变化、目标记录 | 用改组织代替战略选择 |
| 运营模式与结构 | 单元边界、层级、汇报、治理模式不适配 | 组织图、职责、价值链、跨单元事件 | 因部门冲突直接认定结构错误 |
| 治理与权责 | 责任、权力、资源和风险不匹配 | 授权表、决策案例、升级记录 | 把制度存在等同于实际授权有效 |
| 流程与信息 | 等待、返工、接口、数据或系统失效 | 流程周期、工单、会议和系统记录 | 以流程问题为由掩盖权力冲突 |
| 能力与资源 | 领导、人才、专业、数据或容量不足 | 能力评估、负荷、质量和人员数据 | 只换人，不验证系统是否允许成功 |
| 绩效与激励 | 指标冲突、资源竞争、局部最优 | 目标、绩效、预算和激励规则 | 口头要求协同但奖励仍相互冲突 |
| 执行与个体 | 纪律、行为、人岗匹配或一次性失误 | 重复性、跨人员比较、行为事实 | 把个体问题泛化为组织问题 |

多个解释可以同时成立。诊断应识别主要原因、放大因素和触发因素，而不是强行寻找唯一原因。

## 3. 组织问题的五项证据门槛

把下列条件作为检查清单，不机械打分：

1. **重复性**：跨人员、跨事件、跨周期或跨单元反复出现；
2. **系统性**：与责任、权力、资源、边界、协同、绩效或信息安排稳定相关；
3. **经营相关性**：影响客户、收入、成本、速度、质量、创新、风险或人才结果；
4. **替代解释检验**：战略、流程、能力、领导、激励和执行解释经过证据比较；
5. **可干预性**：改变组织机制有清晰路径影响结果。

缺少重复性时，优先检查事件和个体；缺少系统性时，优先检查流程或执行；缺少经营相关性时，不把组织调整升级为优先事项。

## 4. 结构调整的必要性检验

### 更可能需要结构调整

- 结果责任长期落在一个单元，关键资源和决定权稳定属于另一个单元；
- 客户或端到端价值流被现有部门边界持续切断；
- 同一岗位存在不可调和的双重第一责任或多头汇报；
- 业务阶段、规模或组合已经变化，现有单元划分仍围绕旧价值来源；
- 局部权责、流程或绩效修复已试行，关键矛盾仍由结构边界重复制造。

### 更可能先做机制修复

- 结构本身能够支持目标，但职责、授权阈值或会议规则不清；
- 制度已有明确权责，但执行、能力、数据或监督不到位；
- 问题集中于少数人员、单一事件或短期资源不足；
- 主要冲突来自目标和激励不一致；
- 组织尚不具备承接分权、矩阵或新业务单元的能力条件。

## 5. 反证问题

每个结论至少回答一个能够推翻它的问题：

- 如果换一个负责人，问题是否仍会出现；
- 如果不改汇报关系，只调整决策权和绩效，问题是否可能消失；
- 是否存在使用相同结构但结果良好的单元；
- 问题是否只在战略频繁变化、资源不足或系统故障期间发生；
- 是否已有局部授权或例外安排，限制了“全面失配”的结论；
- 结构调整后，哪个具体决策、流程或客户结果会以何种机制改善。

## 6. 最小充分干预原则

比较每种干预的：

- 作用机制；
- 预期收益；
- 协同与迁移成本；
- 风险和副作用；
- 能力与系统前提；
- 可逆性；
- 验证周期。

选择能够切断主要问题机制的最低干预层级。只有当较小干预不能解决结构性矛盾，才进入完整组织设计。
