# 企业战略、组织与人力研究

## 目标

围绕一个目标企业，解释它面对什么变化、选择如何竞争、需要怎样运作，以及这些选择对组织能力和人力资源提出什么要求。

把研究结果做成后续组织、人才、机制和文化工作的核心输入，而不是一份孤立的行业报告。

## 分析原则

底层推理仍沿以下链条检查，不从行业趋势直接跳到 HR 建议：

`外部竞争与行业挑战 → 战略与业务定位 → 关键业务运作方式 → 组织运作模式 → 核心组织能力 → 组织与人力资源要求`

但不要把这条链直接写成报告目录。面向读者的报告必须以行业证据和代表性企业对标为主线：先建立行业共同挑战，再用同口径数据比较企业战略与经营表现，继而比较组织模式，最后形成对目标企业的启示。

完整读取 [business-to-hr-framework.md](references/business-to-hr-framework.md)，用它在后台检查因果连接；完整读取 [report-writing-framework.md](references/report-writing-framework.md)，用其中四章结构组织前台报告。

## 工作流程

### 1. 在正式研究前确认输入

先确认：

- 目标企业及所属业务或区域
- 本次研究服务于什么后续任务或管理问题
- 希望覆盖的时间、地区和业务范围
- 用户是否有内部材料、访谈记录、制度文件、业务数据或已有研究可以补充
- 内部材料是否有保密、引用或输出限制

只需做一次简短确认，不要求用户预先整理完整来源清单。用户没有内部资料时，说明将先基于公开资料形成初步研究并继续。

完整读取 [research-inputs.md](references/research-inputs.md)，按其中规则处理公开资料和用户材料。

### 2. 默认主动检索公开资料

除非用户明确限制联网检索，否则主动搜索并实际阅读可访问的公开材料。优先顺序如下：

1. 公司年报、招股书、交易所公告、投资者关系材料
2. ESG、可持续发展或企业社会责任报告
3. 公司官网、业务和产品页面、治理与管理层页面
4. 政府、监管机构、统计机构和行业协会材料
5. 可公开访问的券商研报和研究机构报告
6. 公司管理层公开演讲、采访和业绩说明会记录
7. 有原始来源或方法说明的专业媒体与数据库
8. 招聘信息、员工内容和社交信息，只作为组织假设线索

搜索结果摘要、无法打开的付费报告标题和模型记忆不算已读取来源。券商研报属于分析性二手来源，不替代企业正式披露或原始数据。

官方 PDF 无法打开时，依次尝试交易所披露、公司网页版本、业绩公告或同一材料的其他语言版本。只记录实际读取的内容，并把未读取全文写入研究限制。

开始分析前读取 [research-standards.md](references/research-standards.md)，处理来源可信度、指标口径、数据冲突和引用。

### 3. 整合用户材料

若用户提供内部资料：

- 保留材料原始路径、文件名、日期和适用范围。
- 将公开资料与内部资料分开标识。
- 优先用内部资料验证实际组织运作、权责、人才和机制，不把内部单一观点直接当作全公司事实。
- 遵守用户给出的保密和引用限制；不得把内部信息写入面向公众的版本。
- 若内部资料与公开资料冲突，呈现差异并分析口径、时间或立场，不静默选择。

### 4. 建立研究证据

先提取事实，再形成判断。关键证据至少记录：

| 字段 | 内容 |
|---|---|
| 研究问题 | 该材料回答哪一个问题 |
| 原始事实 | 数据、原文含义或可观察信息 |
| 来源 | 材料名称、链接或原始路径 |
| 日期与口径 | 数据期间、范围、单位和定义 |
| 证据属性 | 公开事实、内部事实、分析观点或线索 |
| 能支持什么 | 可直接支持的判断 |
| 不能支持什么 | 仍需验证的部分 |

明确区分：

- **事实**：来源直接披露的内容
- **计算**：由已列明数据和公式得到的结果
- **推断**：多项证据支持的解释
- **假设**：需要内部资料、访谈或数据进一步验证的命题

公司对战略、组织能力或文化的公开表述可以证明“管理层如何定义它”，不能单独证明相关能力已经形成或机制实际有效。使用经营数据、案例结果或独立材料进一步验证。

### 5. 建立代表性企业对标样本

除非研究范围明确不适用，选择目标企业及 4 至 6 家代表性企业组成比较样本。样本应覆盖：

- 与目标企业直接竞争、规模或客群可比的企业
- 在经营效率、增长模式或组织模式上具有鲜明特征的企业
- 必要时纳入 1 至 2 家海外参照企业，扩展组织模式视野

先说明入选理由和可比边界，再建立统一指标表。不能只因资料丰富而选样，也不能把规模、地区、会计期间明显不可比的数据直接排序。

### 6. 按“行业—企业—组织—启示”完成分析

依次回答：

1. **行业赛道**：市场结构、消费与技术趋势、宏观环境、业务挑战和管理挑战是什么
2. **企业战略与经营**：代表性企业分别如何定位、增长和运作；同口径经营指标暴露了什么差异
3. **组织模式**：各企业用怎样的结构、管控和协同方式支持战略；形成了哪些组织优势与局限
4. **目标企业启示**：哪些战略—经营—组织差距最值得目标企业关注；对组织、人才、机制和文化提出什么任务

每组指标对比后都要写小结，解释差异可能对应的战略和组织机制。组织模式分类若主要依据公开资料，应说明证据基础和推断边界；获得内部资料后再验证实际权责、流程和机制。

### 7. 形成可供后续 Skill 调用的交付

默认输出两部分：

#### A. 企业战略—组织—人力研究报告

保留固定的报告表达框架：封面、目录、摘要和四章正文。

1. 行业赛道整体洞察
2. 代表性企业业务战略洞察与优劣势分析
3. 代表性企业组织模式与优劣势分析
4. 对目标企业的组织与人力启示

完整读取 [report-writing-framework.md](references/report-writing-framework.md)，按其中的章节目标、比较方法、段落结构和视觉组件撰写。四章是稳定的叙事外壳，但小节数量按研究对象调整。只有用户明确要求 HR 专题研究时，才把第四章中的 HR 启示扩展为独立第五章。

复杂研究先交付证据底稿、核心论证链和组织情境输入卡，再扩写完整报告。若底稿暴露口径冲突或关键证据缺失，先修正研究，不用排版掩盖问题。

#### B. 组织情境输入卡（内部工作底稿）

用结构化表格输出：

| 字段 | 内容 |
|---|---|
| 目标企业与发展阶段 | 企业、业务范围及当前阶段 |
| 外部关键挑战 | 对战略和组织影响最大的变化 |
| 战略优先级 | 企业必须做出的关键选择 |
| 关键业务运作 | 战略落地所依赖的流程和协同 |
| 组织运作假设 | 结构、权责、管控、决策和协同要求 |
| 核心组织能力 | 必须形成的集体能力及业务理由 |
| 人力资源要求 | 组织、人才、领导力、绩效、激励和文化要求 |
| 证据强度 | 强、中、弱或待验证，并说明依据 |
| 内部验证问题 | 后续需通过资料、数据或访谈确认的问题 |

该输入卡供后续组织诊断、组织设计、人才、绩效、薪酬或文化 Skill 使用，默认放在附录或另行交付，不取代面向管理者的比较研究报告。不要在本 Skill 中直接设计完整组织方案或 HR 制度。

## 质量检查

- 是否明确目标企业，又通过代表性企业对标而不是目标企业独白形成判断
- 是否区分行业的业务挑战与该类商业模式共有的管理挑战
- 同一组企业是否使用统一口径比较战略、经营效率和人效
- 每组数据后是否解释了差异背后的战略和组织含义
- 是否先比较组织模式，再形成对目标企业的启示
- 核心组织能力是否具体到可观察的集体行为和结果
- HR 要求是否服务于明确的组织任务，而不是套用通用模块
- 是否区分公开事实、内部事实、推断和组织假设
- 是否明确询问过内部材料，并列出需要内部验证的问题
- 关键数字、事实和判断是否可追溯到实际读取的来源
- 是否写明数据截止日期、限制和证据缺口

## 写作与保密

- 使用直接、具体的中文，避免空泛趋势词和机械化表达。
- 不披露私人信息、未公开人事信息或用户限制引用的内部内容。
- 对公开资料无法证明的内容使用“公开资料显示”“初步判断”或“需内部验证”。
- 默认交付 Markdown；只有用户明确需要时才制作 HTML 或 PDF。

## 可选 PDF 生成

用户明确需要 PDF 且已经得到完整 HTML 时，运行：

```bash
python scripts/generate_pdf.py <html路径> [输出PDF路径] [页眉文字]
```

脚本依赖 Python Playwright 和 Chromium。生成后检查封面、分页、表格溢出、页眉页脚和中文字体。
